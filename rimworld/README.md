# 림월드 첫 정착지 안내서

림월드를 처음 시작하는 분을 위한 안내서입니다. **기본 게임 + 바이오테크(Biotech) + 오디세이(Odyssey)** 조합을 기준으로 썼고, 로열티·이데올로기·어노말리는 없는 것으로 가정합니다.

- **읽는 법:** 오늘 바로 시작한다면 [한눈에 보기](#한눈에-보기-공통)부터 [4장 첫 주 체크리스트](#4-첫-주-체크리스트-기본)까지만 보세요. 5장부터는 필요할 때 펼쳐 보는 참고서입니다. 장 제목 끝의 [기본]·[바이오테크]·[오디세이]는 어느 콘텐츠 이야기인지 표시합니다.
- **기준 버전:** 2026년 11월 1일 스팀 기본 브랜치인 **1.6**입니다. 마지막으로 공지된 패치는 1.6.4850(2026-06-08)입니다.
- **용어:** 「」 안의 이름은 공식 한국어판 게임 화면에 나오는 이름입니다. 처음 나올 때는 영어 이름을 괄호에 함께 적었습니다. 맨 아래에 [용어 대조표](#15-용어-대조표-공통)가 있습니다.
- **숫자:** 림월드 위키, 공식 패치 노트, 게임 안 텍스트로 확인한 값입니다. 패치로 바뀔 수 있으니 게임 안 설명이 다르면 게임을 믿으세요.

## 한눈에 보기 [공통]

게임 화면에 나오는 순서대로 정리했습니다. 이 표대로 고르면 됩니다.

| 단계 | 첫 판 추천 | 이유 |
|---|---|---|
| 게임 버전 | 스팀 → 림월드 속성 → 베타: **「없음」**(1.6) | 1.7은 아직 시험용 'unstable' 베타입니다 |
| 언어 | 메인 메뉴 「환경설정」 → 「언어 선택」 → 한국어 | 바이오테크·오디세이까지 공식 번역이 있습니다 |
| 시나리오 | **「추락」**(Crashlanded) | DLC 시나리오 셋은 모두 게임이 '어려운 시나리오'로 표시합니다 |
| 이야기꾼 | **「카산드라 클래식」** 또는 **「피비 칠랙스」** | 위협이 일정한 간격으로 옵니다 |
| 난이도 | **「사용자 지정」**을 고르고 「표준 플레이 유형으로 설정..」으로 **「공동체 건설자」**(또는 「모험 이야기」)를 불러온 뒤 **「아기 항상 건강함」**만 켜기. 아이를 아직 원하지 않으면 「임신 비활성화」도 켜기 | 난이도와 이야기꾼은 게임 중에도 바꿀 수 있습니다 |
| 저장 방식 | **「기본 모드」** | 「철인 모드」는 게임을 만든 뒤 바꿀 수 없습니다 |
| 세계 생성 | 「오염」 0~5%, 「랜드마크」 기본값 | 오염된 땅은 농사와 건강을 망칩니다 |
| 지역 | **「온대림」**, 「평지」 또는 「소형 언덕」, 「성장 기간」이 「연중 계속」이거나 긴 곳 | 가장 쉬운 조합입니다. 강이나 「증기 간헐천」이 있으면 더 좋습니다 |
| 정착민 | 「일반인」 3명. 사격·원예·건설·의학을 나눠 맡기고 「방화광」·「약물광」 등은 빼기 | 셋이 모든 일을 해야 합니다 |

**게임을 시작한 뒤에 기억할 두 가지**

- **「고대 엑소스트라이더 몸체」(바이오테크):** 시작 지도에 있는 잔해입니다. 부서질 때 불이 나니 근처에 집을 짓지 말고, 나중에 멀리서 부수세요. 공짜 「메크링크」를 얻는 길입니다([6장](#6-메카나이터와-오염-바이오테크)).
- **「메카노이드 신호」(오디세이):** 6일째쯤 오는 임무입니다. 수락하면 「중력구동기」와 재료가 떨어집니다. 중력부양선은 선택 사항이고, **본진에서는 「중력닻」을 짓기 전까지 발사하지 마세요.** 닻 없이 발사하면 원래 지도가 통째로 사라집니다([9장](#9-중력부양선-오디세이)).

### 첫 해의 흐름

림월드의 1년은 60일입니다(4개 분기 × 15일, 게임 화면에는 「1분기」~「4분기」로 표시).

1. **1일:** 지붕 있는 방, 침대, 식탁, 조명, 벼 재배구역.
2. **2~7일:** 전력, 주방, 냉동고, 연구소. 6일째쯤 「메카노이드 신호」.
3. **8~15일(1분기 안):** 첫 습격 대비(엄폐물, 「소집」 연습), 수감실. 이어서 돌벽과 개인 침실, 엑소스트라이더 처리. 「카산드라 클래식」은 11일째, 「피비 칠랙스」는 13일째부터 큰 위협을 보냅니다.
4. **16~60일(2~4분기):** 「미소전자공학」 → 「통신기」와 교역, 「메크링크」와 일꾼 메카노이드, 첫 겨울 준비.
5. **둘째 해부터(원할 때):** 「중력닻」, 첫 원정 비행, 궤도 진출, 「중력 코어」 7개 → 「메카노이드 군락」. 서두르지 않아도 됩니다.

### 이야기꾼과 난이도

- **「카산드라 클래식」:** 큰 위협과 휴식이 번갈아 옵니다. 11일째부터 시작합니다.
- **「피비 칠랙스」:** 위협 사이가 깁니다(16일에 한 번). 가장 여유롭습니다.
- 「랜디 랜덤」: 무작위라 갑자기 어려워질 수 있어 첫 판에는 비추천입니다.
- **난이도:** 「공동체 건설자」(위협 30%, 기분 +10, 연구 ×1.2)나 「모험 이야기」(위협 60%, 기분 +5)를 고르세요. 「모험 이야기」는 공식 설명이 '림월드를 처음 하는 전략 게임 경험자'용입니다.
- 이야기꾼과 난이도는 게임 중에도 언제든 바꿀 수 있습니다. 처음엔 낮게 시작해 익숙해지면 올리세요.

**바이오테크 설정 켜는 법:** 난이도 목록에서 「사용자 지정」을 고르고, 「표준 플레이 유형으로 설정..」 버튼으로 「공동체 건설자」나 「모험 이야기」 값을 불러온 뒤 아래 두 가지만 바꾸세요.

| 설정 | 내용 |
|---|---|
| 「아기 항상 건강함」 | 사산, 병약한 아기, 유산, 산모 사망이 없어집니다. **첫 판 추천** |
| 「임신 비활성화」 | 임신이 아예 일어나지 않습니다. 아이를 아직 원하지 않으면 켜세요. 나중에 끌 수 있습니다 |

### 저장 방식: 「기본 모드」

「기본 모드」(Reload anytime)는 언제든 저장하고 불러올 수 있습니다. 「철인 모드」(Commitment)는 실수를 되돌릴 수 없습니다. **이 선택은 게임을 만든 뒤 바꿀 수 없으니** 첫 판은 「기본 모드」로 하세요.

### 세계 생성

- 「플레이 영역」(30/50/100%), 「전반적 강수량」, 「전반적 기온」, 「인구밀도」, 세력 목록은 기본값이어도 됩니다.
- **「오염」(바이오테크):** 처음부터 오염된 땅의 비율입니다(기본 5%). 처음이면 0%로 내려도 되고, 5%로 둔다면 정착할 타일과 주변 4타일 안에 오염이 없는지 확인하세요.
- **「랜드마크」(오디세이):** 호수·계곡·온천 같은 특별한 지형이 얼마나 자주 나오는지 정합니다(「드문드문」 / 보통 / 「빽빽함」). 기본값을 추천합니다.

### 지역 고르기

세계 지도에서 타일을 누르면 정보 창이 뜹니다. 아래 항목을 보세요.

- **생물군계:** **「온대림」**이 가장 쉽습니다. 「건조관목림」도 무난하고, 오디세이의 「초원」은 비교적 쉽지만 불과 가뭄에 약합니다. 나머지는 첫 판에 비추천입니다.
- **「성장 기간」:** 「연중 계속」이 가장 쉽고, 길수록 좋습니다.
- **「평균기온」:** 10~25°C 정도가 무난합니다.
- **「지형」:** 첫 판은 「평지」나 「소형 언덕」이 무난합니다. 언덕이 많을수록 광석과 자연 벽이 늘지만, 「대형 언덕」부터는 잠든 곤충 군락이 든 동굴이 나올 수 있습니다.
- **물:** 강이 있으면 「수력 발전기」(1,100W, 출력은 일정하지만 강이 얼면 멈춤)를 쓸 수 있고 강가에 비옥한 땅이 생깁니다. 봄에 「계절성 홍수」가 날 수 있으니 밭은 물가에서 조금 떨어뜨리세요. 「증기 간헐천」이 있으면 「지열 발전기」(3,600W)를 쓸 수 있습니다.
- **「지질 유형」:** 「화강암」이 가장 튼튼하고(체력 ×1.7) 가공이 느립니다. 「사암」은 가장 빨리 가공되고, 「대리석」은 가장 예쁩니다.
- **세력 기지 바로 옆**(4타일 이내)은 피하세요.

**랜드마크와 지도 특성(오디세이):** 타일 정보에 붙은 특성도 꼭 확인하세요.

- **좋은 것:** 「비옥함」, 「시생나무」(주변 땅을 비옥하게 바꿈, 드묾), 「어류 증가」(드묾), 「식물 증가」, 「지열 활동 활발」, 강이나 해안. 평지나 「소형 언덕」에 강·해안이 있고 「비옥함」까지 붙으면 최고입니다. 드문 특성을 찾느라 오래 헤매지는 마세요.
- **첫 판에 피할 것:** 「독성 호수」, 「고대 독성 배출구」(유독성 낙진이 주기적으로 옴), 「고대 연기 배출구」(며칠씩 햇빛을 가림), 「고대 열기 배출구」(기온 급변), 「감염된 정착지」·「거대 곤충 군락」(잠든 곤충 군락), 「고대 주둔지」(작동하는 경비 장치), 「용암류」·「용암 호수」, 「모래언덕」(흙·식물·간헐천이 없음), 「빙산」(늘 영하), 「마른 땅」(물 없음).
- **조심할 것:** 「계곡」·「동굴」·「균열」 같은 산 랜드마크는 자연 방어선이 되지만 산악 지형입니다. 산악 타일의 절반(대형 언덕은 4분의 1)에는 잠든 곤충 군락이 든 동굴이 있을 수 있습니다. 탐사하지 않은 동굴 입구는 벽으로 막고, 초반엔 산 지붕 아래에 살지 마세요.

### 정착민 고르기

「추락」에서는 후보 8명 중 3명을 데려갑니다. 목록 위쪽 3명이 함께 떠나고 「남겨짐」 아래 후보는 남으며, 끌어서 서로 바꿀 수 있습니다. 「섞기」(Randomize)는 지금 보고 있는 후보 한 명만 새로 뽑고, 횟수 제한이 없습니다. 마음에 드는 사람은 두고 나머지만 다시 뽑으세요.

**기술:** 셋이서 **사격, 원예, 건설, 의학**을 나눠 맡고, 각 기술에 5 이상 + 열정(불꽃 아이콘)이 있는 사람이 하나씩 있으면 좋습니다. 그다음은 조리, 사교, 연구, 채굴입니다. 조련과 예술은 초반에 덜 중요합니다.

**피할 특성**

| 특성 | 문제 |
|---|---|
| 「방화광」 | 불을 끄지 못하고, 주기적으로 불을 지르는 발작을 일으킵니다 |
| 「약물광」, 「약물선호」 | 약물 정책을 무시하고, 약을 못 하면 기분이 떨어집니다 |
| 「나태」, 「게으름」 | 작업 속도 −35%, −20% |
| 「유리정신」, 「신경과민」 | 정신 붕괴 기준 +15%, +8% |
| 「우울증」, 「부정적」 | 기분 항상 −12, −6 |

**좋은 특성:** 「일벌레」(작업 속도 +35%), 「근면성실」(+20%), 「강인함」(받는 피해 ×0.5), 「낙천적」(기분 +12), 「긍정적」(+6), 「철의 의지」(붕괴 기준 −18%), 「확고한 의지」(−9%), 「숙면가」(휴식 회복 +50%), 「빠른 학습가」(학습 +75%).

**「결격 사항」:** 「캐릭터」 탭에서 꼭 보세요. 「단순노동」 불가는 운반·청소·연료 보충을, 「전투」 불가는 싸움·사냥·간수 일을, 「치료」 불가는 의사 일을 막습니다. 정착민 3명 중 적어도 2명은 「단순노동」과 「전투」를 할 수 있어야 합니다.

**「건강」 탭:** 처음부터 임신한 정착민이 나올 수 있습니다.

**인종형(바이오테크):** 후보마다 인종형(Xenotype)과 성장 단계(아기·어린이·성인)를 고를 수 있습니다. **인종형을 바꾸면 그 정착민이 다시 무작위로 뽑히니**, 인종형을 먼저 정하고 「섞기」를 누르세요. 첫 판은 셋 모두 **「일반인」**(Baseliner, 기본값)을 추천합니다. 약점이나 의존성이 없습니다. 다른 인종형은 [7장](#7-아이와-인종형-바이오테크)에, 나만의 인종형 만들기는 [11장](#11-중반-이후-유전자-조작과-생귀오파지-바이오테크)에 있습니다.

## 2. 첫날 체크리스트 [기본]

착륙하자마자 <kbd>Space</kbd>로 게임을 멈추고 아래를 순서대로 하세요. <kbd>1</kbd>·<kbd>2</kbd>·<kbd>3</kbd>은 게임 속도입니다. 「기본 모드」라도 습격이나 큰 결정 전에는 <kbd>Esc</kbd> → 「저장」으로 직접 저장하세요. 자동 저장 주기는 「환경설정」의 「자동저장 간격」에서 바꿉니다.

- [ ] 「구상」 → 「명령」 → 「취급 허용」으로 떨어진 물자를 드래그하거나, 물자를 골라 <kbd>F</kbd>를 누르세요. 「취급 허용」을 오른쪽 클릭하면 「모든 항목 허용」도 있습니다.
- [ ] 무기를 나눠 주세요. 정착민을 고른 채 바닥의 무기를 오른쪽 클릭해 「볼트액션 소총 착용」처럼 「○○ 착용」을 고르면 됩니다. 사격이 가장 좋은 사람에게 소총을, 나머지에게 「리볼버」와 「단검」을 주세요. 방어구(「방탄조끼」, 「방탄바지」, 「강화 방탄모」)는 「○○ 강제 착용」으로 전투 담당에게 입히세요.
- [ ] 「작업」 탭에서 **「중요도 수동조절」**을 켜세요([3장](#3-작업-탭과-계획서-기본) 참고).
- [ ] 「구상」 → 「명령」 → 「벌목」으로 나무를 베세요. 첫 건물은 나무로 지어도 됩니다.
- [ ] 벽 안쪽이 50칸쯤(7×7이나 6×8)인 방에 문을 하나 달고 침대 3개를 놓으세요. 벽으로 둘러싸면 지붕은 저절로 올라갑니다. 맨땅이나 야외에서 자면 기분 −4입니다.
- [ ] 방 안에 식탁과 의자를 놓으세요. 식탁 없이 먹으면 「바닥에서 식사」 −3입니다.
- [ ] 「횃불」이나 「모닥불」로 빛을 확보하세요. 어두우면 「어둠 속」 −5입니다.
- [ ] 「구상」 → 「구역」 → 「저장구역」으로 물자를 모을 자리를 그리세요. 식량·의약품은 밖에 두면 상하니 첫 방 안이나 지붕 있는 창고에 두세요. 따로 지붕만 씌우려면 「구상」 → 「구역」 → 「지붕 건설 구역」을 씁니다.
- [ ] 「구상」 → 「구역」 → 「재배구역」으로 5×5 밭 4개를 그리세요. 구역을 고르면 나오는 「○○ 심기」 버튼을 눌러 **「벼」**로 바꾸세요. 「딸기」는 원예 5, 「약뿌리」는 원예 8이 있어야 심어집니다. 기술이 모자라면 작물을 고를 때 심을 사람이 없다는 경고가 뜨고, 밭은 빈 채로 남습니다.
- [ ] 지도에 「고대 엑소스트라이더 몸체」가 있으면 그 근처에 침대·목재·저장구역을 두지 마세요. 부서질 때 반경 5칸에 불이 납니다([6장](#6-메카나이터와-오염-바이오테크) 참고).

## 3. 작업 탭과 계획서 [기본]

「작업」 탭(<kbd>F1</kbd>)에서 「중요도 수동조절」을 켜면 칸마다 1~4를 줄 수 있습니다. **숫자가 작을수록 먼저 합니다.** 1인 일이 하나도 없을 때만 2인 일을 하고, 같은 숫자끼리는 왼쪽 칸부터 합니다. 빈칸은 하지 않는다는 뜻입니다. 그래서 「운반」을 1에 두면 지도 위 모든 물건을 나르느라 다른 일을 못 합니다.

| 일 | 추천 |
|---|---|
| 「소방」, 「요양」, 「휴식」, 「심부름」 | 모두 1 |
| 「치료」 | 의학이 가장 높은 사람 1 |
| 「조리」, 「건설」, 「재배」, 「연구」 등 전문 일 | 가장 잘하는 사람 1~2 |
| 「운반」, 「청소」 | 3~4 |

- **「일정」 탭(<kbd>F2</kbd>):** 시간마다 「자유행동」·「작업」·「오락」·「수면」을 정하고, 정착민별 「허가구역」을 고릅니다. 하루 몇 시간은 「오락」으로 두세요. 정착민은 「주거구역」 안에서만 불을 끄고 청소·수리를 하니, 밭까지 「주거구역 설정」으로 넓혀 두세요.
- **「정책」 탭(<kbd>F3</kbd>):** 의복, 음식, 약물, 「의료 관리」, 의약품 휴대를 정합니다.
- **작업대 「계획서」:** 작업대를 골라 「계획서」 → 「계획서 추가」를 누르고 「설정한 횟수 작업」, 「정해진 만큼 작업」, 「계속 반복」 중에서 고릅니다. 식사는 「정해진 만큼 작업」으로 10~20개를 유지하게 하면 편합니다. 목록 위의 작업부터 처리합니다.
- **저장구역 우선순위:** 「낮음」·「중간」·「선호」·「중요」·「필수」가 있고, 일꾼은 더 높은 우선순위의 빈자리로 물건을 옮깁니다. 「처리구역」은 처음 필터만 다른 저장구역입니다.

## 4. 첫 주 체크리스트 [기본]

1~7일에 할 일입니다.

- [ ] **전력:** 「나무 화력발전기」(1,000W)로 시작해 「축전지」와 「태양광 발전기」 연구로 넘어가세요. 강이 있으면 「수력 발전기」, 「증기 간헐천」이 있으면 「지열 발전기」가 좋습니다.
- [ ] **주방:** 「스토브」를 골라 「계획서」 → 「계획서 추가」 → 「간단한 식사 준비」를 누르고, 「정해진 만큼 작업」으로 10개쯤 유지하게 하세요. 전기가 생기면 「전기 스토브」로 바꿔도 됩니다. 바닥을 깔고 청소하면 식중독이 줄어듭니다. 도축은 주방 밖에서 하세요(「간이 도축 장소」나 「도축 작업대」).
- [ ] **냉동고:** 별도 방에 「냉방기」를 달고 **목표 온도를 −5°C 정도로 낮추세요.** 새로 설치한 냉방기는 21°C로 맞춰져 있어서 그대로 두면 음식이 썩습니다. 뜨거운 쪽(빨간 쪽)은 바깥을 향해야 합니다. 더운 날에는 10×10 방에 냉방기 2~3대가 필요합니다. 음식은 0°C 이하에서 썩지 않고, 10°C 아래에서는 천천히 썩습니다.
- [ ] **연구소:** 「연구 작업대」를 침실이 아닌 작은 방에 따로 두세요. 1.6부터 작업대가 맞지 않는 방에 있거나 야외에 있으면 작업 속도가 ×0.8입니다. 연구 작업대는 「연구소」, 스토브는 「주방」, 「석재 절삭대」·재봉·단조 작업대는 「작업소」에 두면 됩니다.
- [ ] **6일째쯤 「메카노이드 신호」:** 화면 오른쪽에 편지가 뜨면 눌러서 읽고 「수락」하세요. 놓쳤으면 화면 아래쪽 「임무」 탭에서 수락할 수 있습니다.
    - 수락하면 메카노이드 함선이 근처에 추락하며 「중력구동기」, 「중력감응판」, 「메카노이드 함선 잔해」, 메카노이드 시체가 떨어집니다.
    - 함선 잔해는 운반할 수 없으니 그 자리에서 해체하세요(하나당 강철 40 + 중력감응판 15).
    - 정착민 하나로 「중력구동기 조사」를 하면 「기초 중력기술」 연구가 열립니다([9장](#9-중력부양선-오디세이) 참고).
- [ ] **습격 대비:** 큰 위협 전에도 작은 습격이 먼저 올 수 있습니다. 빨간 편지가 뜨면 일시정지하고, 싸울 정착민을 골라 「소집」(<kbd>R</kbd>)을 누르세요. 소집된 정착민은 오른쪽 클릭으로 옮기고 공격시킵니다. 엄폐물 뒤에 세우고, 싸움이 끝나면 「해제」를 눌러 일터로 돌려보내세요. 첫 주에 한 번 연습해 두세요.

### 할 일 목록

- [ ] 나무 벽을 돌벽으로 바꾸세요. 「석재 절삭대」에 「화강암 석재 만들기」 같은 계획서를 걸고, 1.6부터는 나무 벽 위에 돌벽 설계도를 바로 놓을 수 있습니다.
- [ ] 정착민마다 **개인 침실**을 주세요. 막사에서 자면 방이 「상당히 인상적인 막사」 단계가 되기 전까지 기분이 −7~−1입니다. 평범한 침실만 줘도 0~+1이라, 작은 침실이 막사보다 기분이 5쯤 높습니다.
- [ ] 「목화」, 「옥수수」, 「약뿌리」 밭을 늘리고 「식당」 겸 휴게실을 만드세요.
- [ ] 「수감실」(침대를 「수감용」으로 지정)을 만들어 두세요. 습격자를 사로잡아 영입하는 것이 인원을 늘리는 주된 방법입니다.
- [ ] 부품(Component)을 아끼세요. 발전기, 냉방기, 축전지, 통신기, 첨단 연구 작업대에 들어가고, 전기 기기는 가끔 고장 나 수리할 때마다 하나씩 씁니다. 「함선 파편」 3개를 해체하고(각 강철 20 + 부품 5~6), 「매몰된 기계장치」를 채굴하고(각 2), 상인에게 사세요.
- [ ] **첫 겨울 준비:** 「성장 기간」이 「연중 계속」이 아니면 그 기간이 끝난 뒤에는 밭이 자라지 않습니다. 겨울이 오기 전에 냉동고에 식량을 넉넉히 쌓고, 「재봉 작업대」에서 「파카」를 만들어 입히세요. 성장 기간은 세계 지도에서 정착지 타일을 누르면 다시 볼 수 있습니다.
- [ ] 무덤이나 「처리구역」을 만들어 시체를 치우세요. 썩는 시체는 「부패 가스」(기분 −10)를 내고, 1.5부터 「폐렴」(lung rot)을 일으킬 수 있습니다.

### 방어

- **「소집」:** 습격이 오면 싸울 정착민을 골라 「소집」(<kbd>R</kbd>)하고, 끝나면 「해제」하세요([4장](#4-첫-주-체크리스트-기본) 참고).
- **습격 규모:** 습격 점수로 정해지고, 점수는 대략 (정착지 재산 + 정착민·동물 전투력) × 난이도 등으로 계산됩니다. 그래서 재산과 인원이 늘면 습격도 커집니다. 은이나 예술품을 지킬 수 없을 만큼 쌓지 말고, 재산이 늘면 방어도 같이 늘리세요.
- **엄폐:** 벽은 최대 75%, 「모래주머니」와 「엄폐물」은 55%, 바위 덩어리는 50%, 나무는 25%를 막습니다.
- **배치:** 사수는 엄폐물 뒤에 모여서 쏘게 하세요. 쏘는 사람 근처(약 5칸) 아군은 오발에 맞지 않습니다. 위험한 건 사선 앞쪽에 선 아군입니다. 근접 담당은 사선 앞으로 내보내지 말고, 1칸짜리 문 바로 안쪽 옆에 세워 문으로 들어오는 적을 하나씩 맞게 하세요.
- **입구:** 기지의 주 출입구를 하나로 정해 병목을 만드세요.
- **포탑:** 「소형 기관포」(80W)는 「자동 포탑」 연구가 필요합니다. 많이 쏘면 강철로 총열을 갈아야 하고, 망가지면 폭발할 수 있습니다.
- **습격 방식:**
    - 지도 가장자리에서 걸어오기(기다렸다 공격하기도 함)
    - 정착민 머리 위로 낙하기 투하: 적이 기지 한가운데로 떨어질 수 있습니다. 두꺼운 산 지붕 아래로는 떨어지지 못합니다.
    - 흩어진 낙하기
    - 부족 세력은 낙하기를 쓰지 못합니다.
- **「식인동물 무리」:** 동물은 문을 열지 못합니다. 모두 실내에 두면 24~54시간 뒤 떠납니다.
- **추락한 함선 잔해(「정신 파동 함선 잔해」·「생태 조작 함선 잔해」):** 메카노이드 경비가 함께 떨어집니다. 함선이나 메카를 공격하거나 근처 5×5 안에 뭔가를 지으면 깨어납니다. 준비가 되기 전에는 건드리지 마세요.
- **산 속 기지:** 산 지붕 아래이고 −17°C보다 따뜻하며 정착지 건물에서 30칸 안인 곳에는 「곤충 군락」이 생길 수 있습니다. 어둡고 바깥과 먼 곳일수록 잘 생기지만 조명으로 막을 수는 없습니다. 초반에는 산 가장자리나 평지에 지으세요.
- **불:** 불씨는 2칸까지 튑니다. 나무 기지 사이사이에 2칸짜리 방화대를 두고, 돌벽으로 바꿔 가세요.

### 연구 순서

| 단계 | 연구 | 비용 | 무엇이 열리나 |
|---|---|---|---|
| 1 | 「축전지」 → 「태양광 발전기」 | 400, 600 | 안정적인 전력. 강이 있으면 「수력 발전기」(700), 간헐천이 있으면 「지열 발전」(3,200) |
| 2 | 「미소전자공학」 | 3,000 | 「통신기」와 「무역 송신기」(교역), 「첨단 연구 작업대」 |
| 3 | 「단조」 → 「기계 가공」 | 700, 1,000 | 「기계 작업대」, 「총기 제작」으로 가는 길 |
| 4 | 「복합 분석기」 → 「정밀 조립」 | 4,000, 4,000 | 부품을 직접 만들 수 있게 됩니다 |

- **「복합 분석기」 주의:** 「기계 가공」과 「첨단 연구 작업대」(부품 10개)가 먼저 필요합니다. 복합 분석기 건물에는 「플라스틸」 50과 「금」 20이 드는데, 「추락」에는 둘 다 없습니다. 채굴하거나 궤도 상인에게서 미리 모아 두세요.
- **필요할 때 끼워 넣을 것:**
    - 방어: 「단조」 → 「기계 가공」 → 「총기 제작」 → 「노리쇠 장치」 → 「자동 포탑」(소형 기관포까지 합계 3,200)
    - 장비와 의료: 「방탄 장비」, 「항균 자재」, 「페녹시실린 제조」(말라리아·수면병·흑사병 예방, 5일마다 복용)
    - 오디세이: 「기초 중력기술」(300), 「낚시」(600). 중력부양선 연료를 만들려면 기본 게임 연구인 「연료 정제」(700)도 하세요
- **연구 속도:** 「연구 작업대」는 ×0.75, 「첨단 연구 작업대」는 ×1.0, 복합 분석기를 붙이면 ×1.1입니다. 「연구소」 밖에 두면 ×0.8이 더 붙습니다.

### 식량

| 작물 | 성장 일수(비옥도 100%) | 실제 걸리는 시간 | 특징 |
|---|---|---|---|
| 「벼」 | 3 | 약 5.5일 | 가장 빨라서 첫 작물로 최고. 수확량 6 |
| 「딸기」 | 4.6 | 약 8.5일 | 날로 먹어도 됨. 원예 5 필요 |
| 「감자」 | 5.8 | 약 10.7일 | 자갈밭처럼 척박한 땅에서도 잘 자람 |
| 「옥수수」 | 11.3 | 약 21일 | 노동 대비 식량이 가장 많고 오래 보관됨. 수경재배 불가 |

식물은 밤에 쉬기 때문에 실제로는 성장 일수의 약 1.85배가 걸립니다.

- 정착민 1명당 **밭 25칸 이상**을 잡으세요. 벼 기준 약 17칸이 최소인데, 그건 모든 조건이 완벽할 때입니다.
- **식사:**
    - 「간단한 식사」: 날것 0.5만큼(벼 10개 정도)으로 영양 0.9짜리를 만들고, 「생식」(날것을 먹음, −7)을 피합니다.
    - 「좋은 식사」: 조리 6 이상, 고기 + 채소, 기분 +5.
    - 「호화로운 식사」: 조리 8 이상, 재료가 두 배, 기분 +12.
- **식중독:**
    - 주방이 지저분하면 식중독 확률이 최대 5%까지 늘어납니다. 주방 청결도가 −2보다 높으면(−1, 0처럼 덜 더러우면) 이 몫은 0입니다.
    - 요리사 실력도 영향을 줍니다. 조리 0이면 5%, 3이면 2%, 5면 1%, 6이면 0.5%입니다.
    - 요리 실력이 6 미만이라고 요리를 막지 마세요. 날것을 먹는 쪽이 더 나쁩니다. 가진 사람 중 최고에게 맡기세요.
- **사냥:** 동물 정보 카드의 「피해 시 보복 확률」을 확인하세요. 가까이서 쏘면 확률이 세 배가 되고 무리가 한꺼번에 덤빌 수 있습니다. 소총으로 멀리서 사냥하고, 「트럼보」나 포식자는 건드리지 마세요. 「폭탄사슴」은 죽을 때 폭발하니 건물에서 멀리 떨어진 곳에서 잡으세요.
- 큰 강이나 바닷가라면 오디세이 **낚시**가 좋은 보조 식량입니다. 작은 연못은 거의 도움이 되지 않습니다([8장](#8-지상-콘텐츠와-낚시-오디세이) 참고).

### 기분

- **정신 붕괴 기준:** 기분이 35% 아래면 가벼운 붕괴(평균 4일마다), 20% 아래면 심각한 붕괴(0.8일), 5% 아래면 극단적 붕괴(0.5일)가 옵니다.
- **자주 보는 기분 요소:** 정착민을 골라 「필요」 탭을 열면 지금 받고 있는 기분 요소가 보입니다.

| 상황(게임 표시) | 기분 |
|---|---|
| 식탁 없이 먹음(「바닥에서 식사」) | −3 |
| 날것을 먹음(「생식」) | −7 |
| 「영양죽 식사」 | −4 |
| 「맛있는 음식」 / 「호화로운 음식」 | +5 / +12 |
| 어두운 곳(「어둠 속」) | −5 |
| 「밖에서 잠」·「바닥에서 잠」·「추운 곳에서 잠」·「더운 곳에서 잠」 | 각 −4 |
| 시체를 봄(「시체 목격」) / 썩은 시체를 봄 | −4 / −6 |
| 「흠뻑 젖음」 | −3 |
| 「야호!」(재미 완전 충족) / 「재미가 결핍됨」 | +10 / −20 |

- **「미관」:** 주변이 「나쁜 환경」·「매우 나쁜 환경」·「끔찍한 환경」이면 −5·−10·−15, 「만족스러운 환경」·「매우 만족스러운 환경」·「황홀한 환경」이면 +5·+10·+15입니다. 바닥 깔기, 청소, 조각상, 잔해 치우기로 올라갑니다.
- **오락:** 처음엔 「편자 막대」와 「체스 탁자」(이미 연구됨)를 놓으세요. 「당구대」는 건설 6이 필요하고, 「음극선관 TV」는 연구가 필요합니다. 하늘 보기, 산책, 수다는 건물 없이 됩니다. 같은 오락만 하면 질리니 종류를 섞으세요.

### 의료

- 의학이 가장 높은 사람의 「치료」를 1로 두고, 모두의 「요양」·「휴식」을 켜 두세요. 의사는 「건강」 탭에서 「자가 치료 허용」을 켜세요(효율 70%).
- 물린 상처와 화상은 30%, 동상은 25%, 대부분의 베인 상처는 15% 확률로 감염됩니다. 치료 품질이 높을수록, 깨끗한 바닥이 깔린 방일수록 확률이 줄어듭니다.
- 「생약」은 가벼운 부상과 동물에, 「의약품」은 심한 부상에, 「번화계 약품」은 수술과 큰 병에 쓰세요. 「정책」 탭의 「의료 관리」로 기본값을 정합니다.

### 죄수, 영입, 교역

- **포획:** 쓰러진 습격자를 정착민으로 오른쪽 클릭 → 「포획」. 「수감실」 침대가 있어야 합니다.
- **영입:** 죄수를 골라 「처우」 탭에서 「포섭」을 고르세요. 「설득」은 저항만 낮추고 영입은 하지 않습니다. 사교가 가장 높은 사람에게 간수를 맡기고, 기술이 좋고 중독이 없는 사람을 영입하세요.
    - 노예화와 개종은 이데올로기 콘텐츠라 이 조합에는 없습니다.
    - 대신 바이오테크에서 「피 주머니」, 「혈액정수 농장」 같은 죄수 처우가 추가됩니다.
- **교역:** 궤도 상인은 무역선이 근처를 지나간다는 편지가 올 때 거래합니다. 정착민으로 「통신기」(200W)를 오른쪽 클릭해 「○○ 연락」을 고르세요. 팔 물건과 은은 「무역 송신기」 범위 안에 있어야 합니다.
    - 「카산드라 클래식」·「피비 칠랙스」에서는 궤도 상인이 대략 15일에 한 번꼴로 지나가고, 16시간쯤 머뭅니다.
    - 우호 세력에게는 통신기로 「상단 요청」(우호도 소모)을 할 수 있습니다.
    - 거래는 사교가 가장 높은 사람이 하세요.
- **세력과 관계:** 쓰러진 방문자의 옷을 벗기거나 손님을 체포하면 관계가 크게 떨어집니다(벗기기 1번에 −40, 체포하면 바로 적대).
- **책(1.5부터 기본):** 소설은 오락, 교재는 기술 경험치, 설계도는 연구 점수를 줍니다. 「정책」 탭의 독서 정책으로 관리합니다.

## 6. 메카나이터와 오염 [바이오테크]

바이오테크는 크게 네 가지를 더합니다. 메카나이터(메카노이드 부리기), 오염, 출산과 아이, 인종형과 유전자 조작입니다. 이 장은 메카노이드와 오염 이야기이고, 「메크링크」를 얻을 즈음 보면 됩니다.

### 메크링크 얻는 순서

「추락」 같은 일반 시작에서 메크링크를 얻는 가장 쉬운 길은 시작 지도에 있는 **「고대 엑소스트라이더 몸체」**입니다.

1. **엑소스트라이더를 멀리서 부수세요.**
    - 체력이 17% 아래로 떨어지면 화학연료가 새고, 약 10초 뒤 반경 5칸에 불이 붙으며 폭발합니다.
    - 마른 풀밭이면 2칸 방화대를 미리 베어 두고, 근접 공격으로 부수지 마세요.
    - 부수면 「메카노이드 통신기」가 나옵니다.
2. **정착민을 고른 채 떨어진 「메카노이드 통신기」를 오른쪽 클릭해 「통신기 해독」을 고르세요.** 연구 작업대가 있어야 합니다. 교역용 「통신기」와는 다른 물건입니다. 해독하면 궤도에 있는 메카나이터 함선 퀘스트가 열립니다.
3. **퀘스트를 수락하면 「추락한 메카나이터 함선」이 근처에 떨어집니다.** 함선을 지키던 메카노이드가 나와 공격합니다.
    - 경비 규모는 해독 시점의 재산에 따라 정해지니, 너무 늦추지 말고 정착민 2~3명이 쓸 만한 총을 갖췄을 때 하세요.
    - 수락하기 전에 퀘스트 설명의 경비 목록을 읽으세요. 「테서론」이 있으면 엄폐와 보호막을 무시하고 불을 붙이는 광선을 쏘니 가장 먼저 집중 사격하세요.
    - 기지에서 떨어진 곳에서 싸우고, 불 끌 사람을 대기시키세요.
4. **함선 안 메카나이터 시체를 정착민으로 오른쪽 클릭해 「메크링크」를 꺼내세요.**
5. **「메크링크」를 쓸 사람으로 오른쪽 클릭해 설치하세요.** 수술 없이 바로 됩니다.
    - 반드시 **야외에서** 하세요. 설치하면 공짜 메카노이드 한 기가 하늘에서 떨어지는데, 실내나 산 지붕 아래면 낙하기가 지붕을 무너뜨립니다.

시작 지도를 떠나기 전에(중력부양선을 닻 없이 발사하기 전에) 이 과정을 끝내세요. 놓치면 언제 올지 모르는 「고대 메카나이터 유적」 퀘스트를 기다려야 합니다.

### 메카나이터는 누구에게

- **「제작」 작업을 할 수 있어야 합니다.** 메카노이드 배양과 수리에 필요합니다.
- **연구를 할 수 있어야 합니다.** 메카노이드 연구를 열 수 있습니다.
- 「정신적 무감각」 특성이 있는 사람은 쓸 수 없습니다.
- 유일한 의사나 최고의 근접 전투원은 피하고, 제작 쪽 지원 담당에게 주세요.
- 메카나이터가 죽거나 대역폭이 모자라면 메카노이드가 「제어되지 않음」 상태가 되고, 하루쯤 지나면 야생화해 적이 될 수 있습니다.
    - 그 전에 대역폭에 여유가 있는 메카나이터로 그 메카노이드를 오른쪽 클릭해 「○○ 제어」를 고르면 다시 연결됩니다.
    - 헤드셋을 벗기거나 「대역폭 확장기」 전력이 끊겨도 같은 일이 생깁니다.
- 메카나이터가 지도를 떠나면 「호위」가 아닌 메카노이드는 그 지도에 남습니다. 떠날 때 게임이 호위로 바꿀지 물어봅니다.

### 대역폭과 제어

- **「대역폭」:** 메카노이드는 메카나이터의 대역폭 안에서만 부릴 수 있고, 메크링크의 기본 대역폭은 6입니다.
    - 리프터 같은 가벼운 일꾼은 하나에 1을 씁니다.
    - 첫 보스를 잡기 전에는 기본 6에 「무선통신 헤드셋」 +3을 더한 9에, 「대역폭 확장기」 하나마다 +1(300W, 메카나이터에게 맞춰야 함)을 더할 수 있습니다.
    - 「기본 기계공학」을 연 뒤에는 「통신 배열 헤드셋」(+6)과 「대역폭 팩」(+9, 제작에 「신호 칩」 2개)이 생깁니다.
- **「제어 집단」:** 메카노이드를 집단으로 묶고 집단마다 「작업」·「호위」·「재충전」·「휴면 충전」 중 하나를 정합니다. 제어 집단과 수행 모드는 화면 아래쪽 「메카노이드」 탭(바이오테크가 추가)에서 정합니다. 처음엔 집단이 2개뿐입니다.
    - 1번은 일꾼용 「작업」, 2번은 전투용 「휴면 충전」으로 두세요. 휴면 중에는 에너지를 쓰지 않고 폐기물도 나오지 않습니다.
    - 휴면 충전은 하루 1%씩만 차고, 에너지가 15% 이상이어야 깨울 수 있습니다. 충전기에서 가득 채운 뒤 휴면시키세요.
    - 습격이 오면 전투 집단을 깨워 소집하세요. 「호위」는 메카나이터를 따라다니게 하는 모드라 메카나이터까지 전투로 끌려갑니다.
- **명령 범위:** 소집한 메카노이드는 메카나이터 근처(약 25칸)에서만 명령을 받습니다. 메카나이터는 벽 뒤에 두되 너무 멀리 두지 마세요. 「작업」 모드는 거리와 상관없이 일합니다.
- **수리:** 메카나이터가 직접 고치고, 「자동 수리」를 켜 둘 수 있습니다. 죽은 아군 메카노이드는 몸이 남아 있으면 배양기에서 되살릴 수 있습니다.
- **분해와 연결 끊기:** 메카나이터로 메카노이드를 오른쪽 클릭하면 「○○ 분해」(서브코어와 재료 일부 회수)와 「○○(와)과 연결 끊기」가 있습니다. 대역폭이 모자라 종류를 바꿀 때는 분해를 쓰세요. 연결을 끊으면 제어되지 않는 메카노이드가 됩니다.

### 연구와 첫 메카노이드

| 연구 | 필요 조건 | 주요 해금 |
|---|---|---|
| 「기초 기계공학」 | 메카나이터 | 「메카노이드 배양기」, 「메카노이드 충전기」, 「서브코어 부호기」, 「대역폭 확장기」, 리프터·컨스트럭토이드·아그리핸드·클린스위퍼·밀리터 |
| 「기본 기계공학」 | 「신호 칩」 분석 | 대형 배양기·충전기, 「서브코어 소프트스캐너」, 터널러·스코처 등, 사이클롭스(오디세이) |
| 「첨단 기계공학」 | 「동력집중 칩」 분석 + 「복합 분석기」 연구. 복합 분석기를 붙인 「첨단 연구 작업대」에서 연구 | 「서브코어 립스캐너」, 더 무거운 전투 메카노이드 |
| 「최첨단 기계공학」 | 「나노 구조화 칩」 분석 + 「정밀 조립」 연구. 같은 작업대에서 연구 | 리저너리, 테서론, 센추리온, 워 퀸 등 |

- 칩을 메카나이터로 오른쪽 클릭해 「신호 칩 분석」(다른 칩도 「○○ 분석」)을 하면 해당 연구 프로젝트가 열립니다. 그다음 연구 작업대에서 그 연구를 진행하세요. 이름이 비슷하니 순서를 기억하세요. 기초 → 기본 → 첨단 → 최첨단입니다.
- **처음 짓는 순서:**
    1. 공짜 메카노이드용 「메카노이드 충전기」(강철 125 + 부품 1, 상시 200W)
    2. 「서브코어 부호기」(강철 100 + 부품 3)와 「메카노이드 배양기」(강철 150 + 부품 3, 대기 50W, 배양 중 350W)를 함께
    3. 메카노이드는 하나에 강철 50 + 기본 서브코어(강철 50 + 부품 2)
    4. 대역폭 6을 넘기려면 「무선통신 헤드셋」(강철 50 + 부품 4)
    - 여기까지 부품이 약 13개 듭니다. 부품이 초반의 진짜 병목입니다.
- **첫 일꾼 추천(커뮤니티 의견):** 공짜로 받은 리프터(운반)나 컨스트럭토이드(건설)에, 식량이 빠듯하면 「아그리핸드」(파종·수확), 청소용 「클린스위퍼」, 미끼 겸 예비 전력 「밀리터」 1~3기. 첫 보스를 잡기 전까지는 대역폭 9 안에서 운영하세요.
- 일꾼 메카노이드는 정해진 일만 합니다. 연구, 사교, 간수, 조련, 사냥, 예술은 못 합니다.
- 아군 메카노이드도 재산과 전투력으로 습격 규모를 키웁니다. 전투 메카노이드를 초반에 많이 만들지 마세요.

### 배양과 서브코어

- 「메카노이드 배양기」는 가벼운 메카노이드만, 「대형 메카노이드 배양기」는 중형 이상만 만들고 되살립니다.
- 배양기에 「계획서」를 걸면 일꾼이 재료를 넣고, **메카나이터가 직접 배양 단계를 시작해야** 진행됩니다.
- 메카노이드마다 등급에 맞는 서브코어가 필요합니다.

| 서브코어 | 만드는 곳 | 대가 |
|---|---|---|
| 기본 서브코어 | 「서브코어 부호기」 | 재료만 |
| 표준 서브코어 | 「서브코어 소프트스캐너」 | 넣은 사람이 며칠 앓지만 다치지 않음 |
| 상급 서브코어 | 「서브코어 립스캐너」 | **넣은 사람이 반드시 죽음.** 도중에 취소해도 죽습니다. 처형으로 취급돼 다른 지도에 있는 정착민까지 모두 기분 −6(「누군가를 립스캔 함」)입니다 |

스캐너에는 정착민이 아니라 붙잡은 죄수를 넣으세요.

### 충전기와 독성 폐기물

- 메카노이드가 충전하면 충전기 안에, 배양하면 배양기 안에 「독성 폐기물」(wastepack)이 쌓입니다. 둘 다 운반 담당이 비워 줘야 합니다.
    - 충전기가 차면 「충전기 가득 참」 경고가 뜨고 그 충전기는 쓸 수 없습니다.
    - 운반 담당이나 리프터가 비우게 하거나, 정착민으로 충전기를 오른쪽 클릭해 꺼내세요.
- 「메카노이드 충전기」는 가벼운 메카노이드 전용이고, 중형 이상은 「대형 메카노이드 충전기」가 필요합니다.
- **폐기물은 얼려서 보관하세요.**
    - 얼지 않은 폐기물은 서서히 녹아 주변 땅을 오염시킵니다.
    - 불에 타거나 부서지면 독소 가스를 냅니다.
    - 녹은 폐기물은 곤충 고치를 불러 「폐기물에 이끌린 곤충 군락」을 만들 수 있습니다.
    - 보관 장소: 지붕과 돌벽이 있는 작은 방에 냉방기를 달아 0°C 아래로 두고, 침실·주방·밭에서 떨어진 곳에 짓습니다.
    - 그 방에 **독성 폐기물만 받는 저장구역**을 높은 우선순위로 만들고, 다른 저장구역에서는 폐기물을 빼세요. 음식 냉동고와 같이 쓰지 말고 불탈 물건도 두지 마세요.
    - 한 칸에 5개까지 쌓이고 선반에는 올릴 수 없습니다.
- **버리기:** 되도록 버리지 말고 얼려 두세요. 상단이나 수송 포드로 다른 곳에 버리면 **가장 가까운 세력 기지**가 화를 냅니다. 꼭 버려야 하면 모든 세력 기지에서 멀리 버리세요.
- **영구 처리:** 「폐기물 원자분해기」가 깔끔한 해결책입니다. 다만 연구에 「나노 구조화 칩」이 필요해서 후반 목표입니다.
- **폐기물을 받아 주는 퀘스트**(보상을 주고 폐기물을 떨굼)는 첫 판에서는 거절하세요.

<summary>폐기물을 버릴 때의 관계 패널티</summary>

- 세력 기지 근처에 버리면 25개당 관계가 약 −25입니다. 그 세력이 적대 관계이거나 이번 일로 적대가 되면, 잃은 관계 수치(%)만큼의 확률로 보복이 옵니다(부족은 습격만, 다른 세력은 폐기물 포드나 습격).
- 중립 세력 기지에서 19타일, 동맹·적대 세력 기지에서 17타일 이상 떨어진 곳에 버리면 포드 하나(25개)에 약 −1로 끝납니다.
- 내 정착지 4타일 안에는 버리지 마세요. 「산성 안개」가 생깁니다.
- 오디세이가 있으면 궤도에 버리는 방법도 있습니다(「교역 조합」만 화를 냄).

### 오염

- 오염된 땅 위에 있으면 지붕 아래라도 「중독」이 쌓입니다. 일반 작물은 오염된 땅에서 자라지 못합니다. 오염 표시 오버레이로 확인하세요.
- 「오염된 지형」은 바닥을 깔아도 덮이지 않습니다. 치우거나 정화나무로 흡수해야 합니다.
- **「중독」 단계:** 4%에서 시작, 40%면 구토와 영구 치매·암 위험, 80%면 의식 불명, 100%면 사망입니다.
- **「산성 안개」:** 정착지 주변 세계 타일이 오염돼 있으면 옵니다. 식물 성장이 느려지고 물건이 빨리 상하며 야외 기분이 떨어집니다.
- **오염된 지역의 동식물:** 「독성사슴」(죽을 때 독성 구름), 「황폐쥐」(물리면 중독) 같은 동물과 오염에 강한 식물이 늘어납니다.
- **청소:**
    - 「정화구역」으로 지정하면 정착민이 오염된 땅을 치우고, 「오염물질 펌프」는 자동으로 거릅니다. 둘 다 오염을 **다시 독성 폐기물로 바꿀 뿐**입니다.
    - 정말로 없애는 것은 「정화나무」와 「폐기물 원자분해기」뿐입니다. 정화나무는 하루 약 2.4칸을 정화하는데, 쉬지 않고 일하는 대역폭 1짜리 메카노이드 한 기가 내는 폐기물(하루 약 5칸 분량)의 절반도 처리하지 못합니다. 메카노이드 폐기물은 냉동 보관했다가 「폐기물 원자분해기」로 처리하세요. 옮겨 심을 수 없고(씨앗만 심을 수 있음), 가까이 건물이 있으면 멈춥니다.
    - 「독감자」는 오염된 땅에서만 자라는 작물일 뿐 오염을 치우지는 않습니다.
- **막는 게 최선:** 첫 판에서는 「독소 발전기」(주변을 오염시키며 전기를 냄)를 짓지 마세요.
- **오디세이와 함께:** 「스카랜드」, 「독성 호수」, 「고대 독성 배출구」는 오염까지 딸려 옵니다. 1.6.4566부터 중력부양선이 내려앉아도 오염이 지워지지 않으니, 착륙하거나 정착하기 전에 타일의 오염을 확인하세요. 떠나는 지도에 폐기물을 두면 그 타일도 오염됩니다.
- **장비:** 「마스크」(독성 환경 저항 +50%, 1.6부터 기본 게임), 「방독면」(+80%, 「기계 가공」), 「독성정화 폐」·「독성정화 신장」(「독소 여과」 연구).
- **독소 가스:** 웨이스터 해적은 독소 가스 무기를 즐겨 쓰고, 타거나 부서진 폐기물도 독소 가스를 냅니다. 「방독면」과 「진공 방호복 헬멧」은 독소 가스를 완전히 막지만 「마스크」는 중독을 줄이기만 합니다.

## 7. 아이와 인종형 [바이오테크]

정착민이 임신했거나 다른 인종형을 영입할 때 보는 장입니다.

### 아이: 낳을지부터 정하세요

**피임과 설정**

- 정착민을 골라 「관계」 탭에서 연인·약혼자·배우자마다 「임신 접근 방법」을 고를 수 있습니다. 「일반」(×1), 「피임」(×0.25), 「임신 시도」(×4) 세 가지입니다.
- 「피임」도 확률을 1/4로 줄일 뿐이고, 새로 생긴 커플마다 따로 설정해야 합니다.
- 확실히 막으려면 침대를 따로 쓰게 하거나, 「생식 의학」(1,000) 연구 뒤 「피임기 이식」, 「정관 절제」, 「난관 결찰」(영구) 수술을 하세요. 아예 원하지 않으면 「임신 비활성화」 설정을 켜면 됩니다.
- 둘 다 16살 이상인 커플이 같은 침대에서 사랑을 나눠야 임신이 됩니다.

**임신과 출산**

- 임신은 18일이고 6일씩 세 단계로 나뉩니다. 마지막 6일은 이동 속도가 절반이 되고 허기가 +50% 늘어납니다.
- 출산이 6일 안으로 다가오면 준비하라는 편지가 옵니다. 준비할 것은 깨끗한 바닥과 좋은 침대가 있는 방, 실력 좋은 의사, 「육아」 담당 1명 이상, 아기 식량, 「아기 침대」입니다.
- 진통이 시작되면 산모를 골라 **「출산을 위해 모임」**(Gather for birth)을 누르세요. 의사와 가족이 모이고, 침대(가능하면 의료용)를 씁니다. 실내의 깨끗한 침대와 의사가 있으면 됩니다.
- 「아기 항상 건강함」 설정을 켰다면 출산 사고는 걱정하지 않아도 됩니다.

<details markdown="1">
<summary>「아기 항상 건강함」을 껐다면: 출산 품질과 신생아 질환</summary>

- 출산 품질은 여러 요소의 합입니다.
    - 가장 큰 요소는 산모의 나이입니다. 20~30살이면 그것만으로 +50%(산모 사망 약 3%)입니다.
    - 실내의 침대와 의사가 있으면 약 70%(산모 사망 약 1.4%)가 됩니다.
    - 의사 없음은 최대 −25%, 더러움 −10%, 야외 −5%, 사랑하는 사람 부재 −5%입니다.
    - 품질이 20% 아래로 내려가면 사산과 산모 사망이 급증합니다.
- 병약하게 태어난 아기는 「신생아 질환」을 앓습니다. 심해지면 며칠 안에 죽을 수 있으니 침대에 눕혀 좋은 약으로 계속 치료하세요.

</details>

**아기(0~3살)**

- 기본 설정에서 아기 시기는 45일입니다. 하루 두 번쯤 먹이는데, 한 번에 최대 2시간이 걸립니다. 먹이는 모유(「수유」), 「이유식」, 「우유」, 「곤충 젤리」입니다.
- 「이유식」은 채식 재료로 「모닥불」이나 「스토브」에서 만들고, 식중독이 전혀 없는 가장 안전한 예비 식량입니다. 어른 음식 정책에서는 빼 두세요(어른이 먹으면 −5).
- 「육아」 작업(사교 기술 사용)을 1~2명에게 켜 두세요. 젖 먹이기, 놀아 주기, 따뜻한 곳으로 옮기기가 모두 육아입니다.
- 「아기 침대」는 재료 25로 연구 없이 만들 수 있습니다. 침실에 놓아도 「막사」가 되지 않습니다.

**어린이(3~13살)와 청소년(13~18살)**

- 기본 설정에서 아이는 어른보다 4배 빨리 자랍니다. 11~20살 사이에서 서서히 느려집니다.
- **나이별로 할 수 있는 일:**
    - 3살: 심부름, 운반, 청소, 육아
    - 7살: 소방, 조련, 조리, 사냥, 재배, 채굴, 벌목, 재봉, 가공
    - 10살: 치료, 간수, 건설, 예술
    - 13살: 모든 일(이때부터 사실상 성인 취급)
- **「학습」:** 아이에게는 오락 대신 학습 욕구가 있습니다. 「자연에서 뛰어놀기」, 「하늘 보며 상상하기」, 독서, 수업 등으로 채웁니다.
    - 일정이 「오락」이나 「자유행동」일 때만 학습하니 「작업」으로만 채우지 마세요.
    - 「교실 책상」 옆에 「칠판」을 최대 3개 두면 학습이 +60% 됩니다(둘 다 「가구」 연구 필요).
- **성장 순간:** 7·10·13살 생일입니다. 그때까지 쌓인 「성장 등급」(0~8)에 따라 고를 수 있는 특성과 열정 수가 정해집니다. 등급 0~3은 열정을 하나도 못 받으니 학습을 잘 채워 주세요.
- **위험:** 무장하지 않고 싸운 적 없는 아이는 습격자가 무시하는 편입니다. 다만 유탄, 불, 굶주린 포식자에는 다칩니다. 아이가 멀리 뛰어놀러 나가는 것도 조심하세요.
- **기분:** 기분 좋은 아이 1명당 어른 전체 기분 +2(최대 +6)입니다. 기분 나쁜 아이는 반대로 −2씩 깎습니다.

**「성장 배양기」**

- 「성장 배양기」 연구(500, 「미소전자공학」 필요)로 열립니다.
- 배아를 9일 만에 아기로 만들고, 아기·아이를 20배 빨리(3일에 1살) 키웁니다.
- 아기 시기를 건너뛰는 데만 쓰세요. 3~13살을 배양기에서 보내면 성장 등급이 쌓이지 않아 열정 없이 자랍니다.

**근친:** 부모·자식·형제·사촌끼리 커플이 되면 「근친생」 유전자(대사 −2, 느린 학습, 생식력 ×50%)가 생길 수 있습니다.

## 8. 지상 콘텐츠와 낚시 [오디세이]

오디세이는 중력부양선 말고도 지상에 많은 것을 더합니다. 새 생물군계 5개(「초원」, 「빙식평원」, 「어둠숲」, 「용암지대」, 「스카랜드」), 랜드마크와 지도 특성, 낚시, 동물 40여 종, 고유 무기, 드론, 새 날씨입니다. 생물군계와 랜드마크 고르는 법은 [1장](#1-새-게임-만들기-기본)에 있습니다.

### 낚시

- **준비:** 「낚시」 연구(600, 선행 연구 없음)를 하고, 「구상」 → 「구역」에서 「낚시구역」을 물고기가 있는 얕은 물 위에 그리세요. 독성 물은 안 됩니다.
- **일꾼:** 1.6.4566부터 「작업」 탭에 「낚시」 칸이 따로 있습니다. 낚시는 조련 기술을 씁니다.
- **구역 설정:** 「낚시구역」을 고르면 나오는 「낚시」 탭에서 반복 방식(「설정한 횟수 작업」, 「정해진 만큼 작업」, 「계속 반복」), 최소 개체 수, 잡지 않을 물고기를 정합니다.
- **개체 수:** 한 물웅덩이의 물고기는 개체 수를 공유하고 하루에 최대치의 2.5%씩만 회복됩니다.
    - **물이 작으면 물고기도 적습니다.** 연못이나 작은 호수에는 수십 마리뿐이라 한 사람도 먹이지 못합니다. 넓은 바다나 큰 강이 돼야 제대로 잡힙니다.
    - 「낚시」 탭에 보이는 그 물의 개체 수를 보고, 최소 개체 수를 최대치의 절반쯤으로 두세요. 여러 물에서 나눠 잡으세요.
- **양:** 흔한 물고기 하나가 영양 0.25입니다. 쌀농사보다 같은 영양에 일이 약 4배 들어서, 낚시는 **보조 식량**이지 주식이 아닙니다. 대신 기온과 상관없이 1년 내내 됩니다.
- **겨울:** 민물은 0°C 아래에서 업니다. 「중량 다리」(「중량 다리」 연구) 위에 벽과 지붕을 세우고 난방하면 얼음을 녹여 겨울에도 낚을 수 있습니다. 바닷물은 얼지 않습니다.
- **위험:** 「아가미 부패병」이 돌면 며칠 동안 물고기가 크게 줄어듭니다. 오염된 물에서는 「독어」가 잡힙니다(바이오테크).
- **덤:** 드물게 지도, 책, 약물, 아주 드물게 고유 무기가 걸려 올라옵니다.

## 9. 중력부양선 [오디세이]

중력부양선은 바닥째 들어 올려 다른 곳으로 날아가는 기지입니다. 원정선으로 쓸 수도 있고, 정착지 전체를 싣고 떠돌 수도 있습니다.

> [!CAUTION]
> **「중력닻」 없이 발사하면 지금 있는 지도가 영원히 사라집니다.** 하부구조 위에 없는 건물, 저장품, 밭, 동물, 사람이 모두 함께 사라집니다. 게임도 발사 전에 "현재 지도와 하부구조 위에 없는 모든 것을 영구히 잃는다"고 경고합니다. 본진에서는 닻을 지을 때까지 발사 버튼을 누르지 마세요.

### 중력구동기 얻기

1. 6일째쯤 「메카노이드 신호」 편지가 오면 「수락」합니다(놓쳤으면 「임무」 탭에서). 메카노이드 함선이 지도에 추락하며 작동하는 「중력구동기」, 메카노이드 시체, 「메카노이드 함선 잔해」, 「중력감응판」이 떨어집니다.
2. 함선 잔해(2×2)는 옮길 수 없으니 그 자리에서 해체하세요. 하나당 강철 40과 중력감응판 15가 나옵니다. 감응판은 모두 저장구역으로 옮기세요. 가장 귀한 재료입니다.
3. 구동기를 골라 「중력구동기 조사」를 누르고 정착민을 고르면 「기초 중력기술」 연구(300, 「연구 작업대」 가능)와 「중력부양선 하부구조」 바닥이 열립니다. 이때부터 「중력 코어」 위치를 알려 주는 퀘스트도 오기 시작합니다.
4. 구동기는 해체할 수 없지만 포장해서 옮겨 다시 설치할 수 있습니다. 반경 약 19칸이 비어 있는 평평한 맨땅(지붕 없는 곳)에 놓으세요. 하부구조는 산 지붕이나 얇은 바위 지붕 아래에는 깔 수 없습니다.

중력구동기는 한 게임에 하나만 가질 수 있습니다. 잃어버리면 무작위로 오는 「중력부양선 잔해」 퀘스트에서만 다시 구할 수 있습니다(메카노이드가 지키고, 나온 뒤 2년 재사용 대기). 구동기는 늘 방어선 안에 두세요.

### 최소 구성

날 수 있는 가장 작은 배는 구동기 + 연결된 하부구조 + 「조종석 콘솔」 1 + 「소형 화학연료 탱크」 1 + 「소형 추진기」 1입니다. 모두 「기초 중력기술」로 열리고, 「구상」의 「중력부양선」 탭에 있습니다.

| 부품 | 비용 | 하는 일 |
|---|---|---|
| 「중력부양선 하부구조」 | 칸마다 중력감응판 1 + 강철 4 | 배의 바닥입니다. **이 위에 있는 것만** 함께 날아갑니다 |
| 「조종석 콘솔」 | 강철 140 + 부품 3, 건설 4 | 구동기에서 직접 전력을 받으니 전력망이 필요 없습니다 |
| 「소형 화학연료 탱크」 | 강철 120 | 화학연료 250 저장. **탱크에 들어 있는 연료만** 비행에 쓰입니다 |
| 「소형 추진기」 | 강철 180 + 부품 4 | 비행 거리 +10타일, 최대 4개. 갑판 가장자리에 두고 분사구를 바깥 빈 땅으로 향하세요 |
| 「중력부양선 외벽」 | | 하부구조 위에만 짓는 공기가 새지 않는 벽입니다 |
| 「중력닻」 | 플라스틸 300 + 중력감응판 80 + 「고급 부품」 5, 작업량 38,000 | 배가 아닌 **땅 위에** 짓습니다. 발사해도 이 지도가 남습니다 |

- 구동기 하나가 하부구조 500칸(반경 약 19칸)을 지탱합니다.
- 「중력장 확장기」(「중력 코어」 1 + 감응판 35 + 부품 2 + 강철 80)를 지으면 하나에 +250칸씩, 최대 6개(2,000칸)까지 늘어납니다. 확장기는 구동기 반경 안에 둬야 합니다.
- 처음엔 **작게** 지으세요. 구동기, 조종석, 탱크 2개, 소형 추진기 2개(사거리 20)에 밀폐된 방 한두 개(침실, 주방 겸 창고)면 충분합니다.
- 「하부구조 오버레이 표시」를 켜면 연결되지 않은(빨간) 칸이 보입니다.
- **탱크:** 체력이 40% 아래로 떨어지면 폭발해 불붙은 연료를 뿌립니다. 침실에서 떨어진 곳에 벽으로 막아 두세요.
- **연료:** 「연료 정제」 연구(700)로 「연료 정제기」(강철 150 + 부품 3, 170W)를 지으세요. 목재 70(또는 날음식 영양 3.5)으로 화학연료 35를 만듭니다. 배 위에 하나 실어도 됩니다.

### 연구 경로

일반 연구와 섞어서 진행하세요.

1. 「전기」 → **「기초 중력기술」**(300) → 「연료 정제」(700)
2. 「미소전자공학」(「첨단 연구 작업대」), 그다음 「단조」 → 「기계 가공」
3. **「궤도 기술」**(1,000): 진공 방호복, 「산소 펌프」, 「진공 장벽」, 「궤도 탐지기」
4. **「표준 중력기술」**(1,200): 「대형 화학연료 탱크」(750), 「대형 추진기」(+16타일, 「진공암 석재」 50 필요)
5. 「복합 분석기」 → 「정밀 조립」 → 「고급 부품」(고급 부품 제작)
6. **「고급 중력기술」**(2,000): 「중력감응판」 제작(플라스틸 1 + 진공암 석재 5), 「중력 코어 발전기」(1,200W, 고장 없음)

- 「연료 조절기」, 「조종 보조자아 핵」, 「중력부양선 보호막 생성기」는 만들 수 없고 퀘스트, 상자, 궤도 장소에서만 얻습니다.

### 발사

1. 「조종석 콘솔」을 골라 「발사」를 누르고 조종사를 고릅니다.
2. 발사 창에서 확인할 것:
    - **「방문자 강제 추방」**은 항상 누르세요. 다른 세력 사람을 태우고 떠나면 그 세력이 적대할 수 있습니다.
    - **「정착지 동물 탑승」, 「정착지 메카노이드 탑승」**은 정착지 전체가 이사할 때만 누르세요. 원정이라면 데려갈 동물과 메카노이드를 직접 고르세요. 이 버튼은 본진의 운반 일꾼과 방어 전력까지 모두 태웁니다.
    - **'남겨지는 사람' 목록**을 꼭 읽으세요.
    - **「비행 범위 보기」**로 갈 수 있는 거리를 미리 보세요.
3. **연료:** 한 번 날 때마다 타일 하나에 화학연료 10씩 듭니다(아무리 가까워도 최소 50). 「연료 조절기」가 있으면 타일당 7, 두 개면 4로 줄어듭니다. 왕복분 이상, 가능하면 **필요량의 2배**를 채우세요.
4. **발사 품질:** 조종사와 부조종사의 연구 기술, 승무원 수(최대 5명까지 효과), 추진기 수, 「조종 보조자아 핵」으로 정해집니다.
    - 조종 능력은 20% + 연구 기술 1당 7.5%입니다. 연구를 못 하는 사람은 조종할 수 없습니다.
    - 품질에 따라 착륙 뒤 구동기 재사용 대기 시간(화면에는 「구동기 재사용 대기 중: …」)과 사고 확률이 정해집니다. 0%면 10일과 100%, 50%면 2일과 25%, 100%면 약 8시간과 2%입니다.

### 착륙

- 도착하면 직접 위치를 정합니다. 「착륙 지점 이동」으로 옮기고 회전한 뒤 「착륙 지점 확정」을 누르세요.
    - 벽, 통과 불가 지형, 깊은 물, 지붕, 「증기 간헐천」, 독성 폐기물 위에는 내릴 수 없습니다.
    - 「착륙 중단」을 누르면 이 지역에는 내리지 않고 세계 지도에서 근처의 다른 지역에 무작위로 내리며, 착륙 사고 확률이 올라갑니다. 착륙할 자리를 못 찾을 때만 쓰세요.
- **착륙 사고 4가지(모두 가벼움):**
    - 「중력부양선 경착륙」: 배 건물이 조금 부서집니다.
    - 「추진기 고장」: 부품으로 고쳐야 합니다. 여분 부품을 꼭 싣고 다니세요.
    - 「중력구동기 과열」: 재사용 대기가 길어집니다.
    - 「중력 멀미」: 2~5시간 메스꺼움입니다.
- **어디에 내리느냐:**
    - 빈 타일에 내리면 그 자리에 새 정착지가 생깁니다(최대 정착지 수 설정과 무관).
    - 퀘스트 장소에 내리면 그 지도로 들어가고, 위협을 정리하면 정착할 수 있습니다.
    - **세력 기지에 내리면 공격으로 취급되고**, 중립 세력은 적대로 바뀝니다. 근처 빈 땅에 내리세요.
- 중력부양선이 있는 지도에서 상단을 꾸려 떠나면 배를 버리게 됩니다. 떠날 때는 언제나 조종석 콘솔의 「발사」로 떠나세요.

### 초보자 운용법

- **첫 판에서 중력부양선은 선택 사항입니다.** 「메카노이드 신호」는 공짜 강철과 중력감응판만 보고 수락해도 충분합니다. 정착지 전체가 이사할 게 아니면 발사하지 말고, 멀리 있는 중력 코어 퀘스트는 무시해도 됩니다.
    - 중력 코어 퀘스트는 구동기가 설치되어 있는 동안에만 옵니다. 부담되면 구동기를 포장해 보관하세요.
    - 구동기 자체가 재산 2,000짜리라 습격 규모에 들어갑니다.
- **본진 + 원정선으로 시작하세요(커뮤니티 의견).** 닻이 생기기 전까지 배는 땅에 세워 둔 기지의 일부로 쓰고, 퀘스트는 상단으로 다니세요.
- **「중력닻」은 중반 목표입니다.** 고급 부품 5개는 「고급 부품」 연구까지 가야 하고, 하나에 플라스틸 10과 금 3이 더 듭니다. 상인에게서 고급 부품이나 플라스틸을 사면 빨라집니다.
- **원정대:** 닻을 지은 뒤에는 조종사, 부조종사, 전투원, 가능하면 의사까지 3~5명을 보내세요.
    - **지도마다 습격이 따로 옵니다.** 본진과 배 양쪽에 각자 버틸 힘을 남기세요.
- **유랑:** 정착지 전체를 싣고 떠도는 방식은 익숙해진 뒤에 하세요. 두 번째 이후 지도는 기본적으로 광물이 적습니다(「외부 채굴 가능 자원」 설정).
- **먼 퀘스트:** 「중력 코어」 퀘스트는 160타일 떨어진 곳에도 생깁니다. 초기 배는 한 번에 10~40타일밖에 못 갑니다. 여러 번 갈아타야 하고, 내릴 때마다 연료와 재사용 대기가 듭니다.
- **재산:** 중력부양선은 칸마다 강철과 감응판이 들어 재산을 크게 늘립니다. 그만큼 습격도 커집니다.
- **바이오테크:** 떠나기 전에 엑소스트라이더에서 메크링크 얻기를 끝내세요. 버리고 떠나는 지도에 독성 폐기물을 두면 그 타일이 오염됩니다.

- [ ] 연료가 목적지까지 필요량의 2배 이상 탱크에 들어 있다. 추가 연료를 선반에 실었다.
- [ ] 식량, 의약품, 여분 부품(추진기 수리용)을 실었다.
- [ ] 「방문자 강제 추방」을 눌렀고, '남겨지는 사람' 목록을 읽었다.
- [ ] 데려갈 동물과 메카노이드를 골랐다.

## 10. 궤도와 메카노이드 군락 [오디세이]

### 궤도는 어떤 곳인가

- 궤도는 행성과 다른 층입니다. 세계 지도의 「궤도」/「행성」 탭으로 오갑니다. 중력부양선, 「여객 왕복선」, 「수송 포드」(편도)로 갈 수 있습니다.
- 바깥은 늘 **진공 100%, −75°C**입니다. 걸어서 나가는 지도 가장자리가 없고, 날씨와 박격포가 없고, 질병과 곤충 군락도 없습니다. 습격은 「해적 인양단」이나 메카노이드만 옵니다.
- **공기:** 방마다 진공도(0~100%)가 따로 있습니다. 공기가 새지 않는 벽으로 완전히 둘러싸고 지붕을 다 덮은 방만 공기를 유지합니다.
    - **금속 벽과 금속 문**, 「중력부양선 외벽」은 공기가 새지 않습니다. **나무와 돌은 샙니다.**
    - 문을 열면 공기가 섞입니다. 오른쪽 아래의 진공 오버레이 버튼으로 새는 곳을 찾으세요.
- **진공에 그냥 노출되면** 약 42초 만에 쓰러지고 약 50초 만에 죽습니다.

### 궤도에 가기 전 준비

- [ ] 「궤도 기술」 연구를 했다.
- [ ] 밖에 나갈 사람마다 「진공 방호복」(강철 90 + 플라스틸 20 + 부품 3)과 「진공 방호복 헬멧」(강철 40 + 부품 2)을 「기계 작업대」에서 만들었다. 둘을 함께 입어야 진공을 완전히 막고 −75°C도 견딥니다.
- [ ] 밖에 나갈 사람의 의복 정책을 「우주」로 바꿨다. 방호복은 이동 속도를 크게 깎으니 행성에서는 벗기세요.
- [ ] 배의 방이 금속 벽(또는 외벽), 금속 문, 완전한 지붕으로 막혀 있다.
- [ ] 방마다 「산소 펌프」(벽걸이, 강철 100 + 부품 2, 가압 중 150W)와 난방기가 있다.
- [ ] 출입구는 「진공 장벽」 + 금속 문 한 쌍이다. 진공 장벽은 전기가 끊기면 열린 문과 같습니다.
- [ ] 배에 따로 발전기와 축전지를 실었다. 구동기 전력은 조종석 콘솔에만 갑니다. 궤도에서는 풍력이 안 되고, 정전되면 진공 장벽이 열리고 난방이 멈춥니다.
- [ ] 돌아올 연료, 여분 부품, 식량, 의약품을 실었다. 동물은 본진에 두고 왔다.

> [!TIP]
> **바이오테크 메카노이드는 진공에 100% 면역입니다.** 궤도에서 소행성을 캐거나 바깥일을 할 때 메카노이드를 쓰면 방호복이 필요 없습니다. 아이는 「어린이 진공 방호복」(강철 45 + 플라스틸 10 + 부품 3)과 헬멧을 입혀야 하고, 아기는 공기가 있는 방에만 둘 수 있습니다.

### 궤도에서 할 일

- **궤도 장소:** 「궤도 탐지기」(「궤도 기술」, 500W, 지붕 없는 곳에 설치)를 돌리거나 「고대 업링크」 랜드마크를 해킹(연구 6)해서 찾습니다.
    - 소행성(진공암 + 플라스틸·우라늄·금 광석)
    - 궤도 보급품 은닉처, 버려진 플랫폼
    - 「해적 인양단」이 지키는 난파선
    - 포탑과 드론이 있는 위성
    - 메카노이드 플랫폼, 「교역 조합」 플랫폼
- **진공암:** 소행성에만 있습니다. 캐면 약 25% 확률로 「진공암 덩어리」가 나오고, 석재 절삭대에서 「진공암 석재」 20개가 됩니다. 「대형 추진기」와 중력감응판 제작에 필요합니다.
- **조심할 점:** 궤도 지도도 닻 없이 떠나면 사라집니다. 소행성이나 난파선에는 고대 수송 포드(2인용)가 있어 비상 탈출용으로 쓸 수 있습니다.
- **「여객 왕복선」:** 「왕복선」 연구(2,500, 「수송 포드」·「복합 분석기」 필요)를 한 뒤 강철 250 + 플라스틸 150 + 부품 6 + 「왕복선 엔진」 1로 짓습니다(건설 6). 500kg을 싣고 타일당 3의 연료로 62타일까지 갑니다. 궤도에도 가고, 우호 기지와 직접 거래할 수 있습니다. 왕복선 엔진은 퀘스트 보상이나 「교역 조합」 상인 등에서 구해야 하니 생기면 아껴 두세요.

### 중력 코어와 메카노이드 군락

- 구동기가 있으면 「중력 코어 감지됨: …」 퀘스트가 옵니다. 첫 번째는 조사 후 약 하루 뒤에 오고, 이후 열린 퀘스트가 3개 미만일 때 15~30일마다 옵니다.
    - 지상: 「메카노이드 중계기」, 「동굴 입구」(곤충 굴), 「고대 원자로」(늘 「스카랜드」), 「고대 저장고」, 「추락 지점」, 「얼어붙은 테라포머」
    - 궤도: 「메카노이드 플랫폼」, 「궤도 플랫폼」
- 퀘스트 하나마다 「중력 코어」 1개와 중력감응판을 줍니다. 처음 얻는 코어는 「중력장 확장기」에 쓰는 것을 추천합니다(커뮤니티 의견).
- 아무 퀘스트나 **7개를 끝내면 궤도의 「메카노이드 군락」이 드러납니다.**
    - 군락은 대함 무기로 지켜지니 「신호 교란기」(코어 1 + 강철 200 + 감응판 80 + 고급 부품 4, 건설 8)를 먼저 지으세요. 「표준 중력기술」과 「고급 중력기술」 중 어디서 열리는지는 자료마다 달라서, 연구 탭에서 확인하세요.
    - 안에서 숨겨진 「세레브렉스 안정장치」 3개를 부수면 「세레브렉스 코어」를 조작할 수 있습니다.
- **선택:**
    - **「코어 파괴」:** 행성 전체의 적대 메카노이드가 멈추고, 모든 세력과 관계가 +50, 기분 보너스가 붙습니다. 대신 **바이오테크 보스를 다시는 부를 수 없습니다.**
    - **「기술 확보」:** 「세레브렉스 노드」(대역폭 +15, 메카노이드 작업 속도 +12%, 메카노이드 호출 능력)를 얻습니다.
    - 어느 쪽이든 엔딩 크레딧이 나오고 게임은 계속됩니다. 그 뒤로 중력 코어 퀘스트는 끊깁니다.
- 메카나이터로 키우고 있다면 「기본 기계공학」·「첨단 기계공학」·「최첨단 기계공학」을 끝내고 칩을 넉넉히 모은 뒤 「코어 파괴」를 고르거나, 「기술 확보」를 고르세요.

## 11. 중반 이후: 유전자 조작과 생귀오파지 [바이오테크]

음식, 전력, 방어, 의료가 안정된 뒤에 볼 내용입니다.

### 유전자 조작은 중반부터

연구와 건물 순서는 이렇습니다.

1. **「변형유전학」**(1,000, 「전기」 필요): 「유전자 추출기」, 「유전자 저장고」, 「유전자 조합기」가 열립니다.
2. **「유전자 처리기」**(1,500, 「미소전자공학」 필요): 처리기 하나마다 복잡도가 +2 늘어납니다.
3. **「초월유전학」**(2,500, 「정밀 조립」 필요): 「초월입자 캡슐」을 써서 초월 유전자를 넣습니다.

**「유전자 추출기」** 쓰는 법:

- 사람을 넣으면 12시간 뒤 유전자 1~4개짜리 「유전자묶음」이 나옵니다.
- 그 뒤 12~20일 동안 「유전자 재성장」 상태가 됩니다. **이 기간에 다시 넣으면 죽습니다.** 「건강」 탭에서 남은 기간을 꼭 확인하세요.
- 죄수는 기분이 떨어지지만 정착민은 신경 쓰지 않습니다. 「일반인」은 넣을 수 없습니다.

**보관과 조합:**

- 유전자묶음은 전기가 들어오는 「유전자 저장고」(4개 보관)에 넣으세요. 밖에 두면 하루 5씩 체력이 줄다가 사라집니다.
- 「유전자 조합기」의 「재조합」으로 「변형이식체」를 만듭니다. 기본 복잡도 한도는 6이고, 대사 효율 −5 이상을 지켜야 합니다.

**이식:**

- 「변형이식체 이식」을 하면 의사가 생약 4개 이상을 쓰고, 대상은 1~3일 「변형이식 혼수상태」에 빠집니다.
- 변형이식체를 넣으면 **기존 변형인자(xenogene)가 전부 지워집니다.** 「지니」, 「후사르」, 「하이메이트」, 「스타잭」, 「생귀오파지」에게 유전자 하나만 더하려다 원래 능력을 잃는 실수가 흔합니다.
- 생식유전자는 아이에게 전해지지만 변형인자는 전해지지 않습니다.

- **유전자묶음 구하기:** 추출기 말고도 이국적인 물건을 파는 상인, 퀘스트 보상, 그리고 오디세이의 「밀봉된 상자」와 「밀폐 보관기」에서 드물게 유전자묶음, 「초월입자 캡슐」, 「죽음안식 수용 혈청」이 나옵니다.

> [!TIP]
> 첫 판에서는 음식, 전력, 방어, 의료가 안정된 다음에 시작하세요. 건물값은 강철 약 450, 부품 약 13개로 싸지만, 원하는 유전자는 무작위로 천천히 모입니다.

### 나만의 인종형

정착민 화면의 「인종형 생성」을 누르면 「인종형 편집기」가 열립니다.

- **「대사 효율」**은 −5 이상이어야 합니다. 0이면 식사량 ×100%, +1마다 약 10% 줄고(최대 ×50%), −1마다 약 25% 늡니다(최대 ×225%).
- **「유전 가능」**에 체크하세요. 체크하면 생식유전자가 되어 아이에게 전해지고, 나중에 「변형이식체」를 넣어도 지워지지 않습니다. 체크하지 않으면 「변형인자」가 되어 다음 이식 때 전부 지워집니다.
- **「제한 무시」**는 끄세요. 게임도 '매우 쉬워질 수 있다'고 경고합니다.
- **예시:** 「건장함」(받는 피해 ×75%, −2) + 그 정착민 역할의 「뛰어난 ○○」(기술 +8과 열정, −3) = −5. 이대로면 식사량이 ×225%입니다. 쓰지 않을 기술 2개에 「끔찍한 ○○」(+2씩)를 붙이면 −1(×125%), 3개면 +1(×90%)이 됩니다.
- **피할 유전자:** 약물 의존성, 「폭력 불가」, 「자외선 민감성」, 「불 공포증」, 「부싯깃 피부」, 「연약함」, 「추가 통증」, 「약한 면역력」, 「느린 학습」. 사수에게 「근시」는 절대 넣지 마세요.

## 13. 시작 전 준비: 버전·언어·모드 [공통]

### 버전은 1.6으로

- 2026-11-01 기준 스팀 기본 브랜치는 **1.6**입니다. 마지막 공지 패치는 1.6.4850(2026-06-08)이고, 그 뒤에 공지 없이 핫픽스(1.6.4871)가 나온 것으로 보입니다. 정확한 번호는 메인 메뉴의 버전 표시로 확인하세요.
- **1.7**은 2026-10-12에 발표된 업데이트입니다. 게임을 Unity에서 Ludeon의 자체 엔진 Waylith로 옮기고 성능이 2~4배 좋아진다고 합니다. 지금은 스팀 'unstable' 베타 브랜치에만 있습니다.
    - Ludeon에 따르면 겉모습과 플레이는 1.6과 같습니다. 저장 파일은 1.6과 1.7 사이에서 양쪽으로 불러올 수 있습니다.
    - 모드는 대부분 그대로 돌아가지만 노란 '지원되지 않을 수 있음' 경고가 붙습니다. Prepatcher를 쓰는 모드는 작동하지 않고, Harmony는 3.0이 필요합니다.
    - 10년 넘은 PC에서는 실행되지 않을 수 있습니다.
- **추천:** 스팀 → 림월드 → 속성 → 베타에서 **「없음」**을 고르세요. 1.7이 정식으로 기본 브랜치에 오면 그때 넘어가도 저장 파일을 그대로 쓸 수 있습니다.

### 한국어로 바꾸기

메인 메뉴 「환경설정」 → 「언어 선택」 → 한국어. 공식 한국어 번역은 기본 게임, 바이오테크, 오디세이를 모두 다룹니다. 번역은 커뮤니티가 관리하며 Ludeon 공식 저장소(Ludeon/RimWorld-Korean)에 올라갑니다.

### DLC가 켜져 있는지 확인

DLC는 모드가 아니라 확장팩입니다. 메인 메뉴 「모드」 목록에 바이오테크와 오디세이가 확장팩으로 보이고 체크되어 있으면 됩니다.

### 모드는 두 번째 판부터

- 첫 판은 모드 없이 하거나 편의 기능 모드 몇 개만 쓰기를 권합니다(커뮤니티 의견). 'Vanilla Expanded' 같은 대형 콘텐츠 모드는 나중에 쓰세요.
- 모드를 쓴다면:
    - **Harmony**를 목록 맨 위에 두세요. 대부분의 코드 모드가 필요로 합니다.
    - 창작마당 페이지에서 **1.6 태그**가 붙었는지 확인하세요.
    - 2026-11 기준 1.6 태그가 있는 인기 편의 모드: Pick Up And Haul, RimHUD, Allow Tool(HugsLib 필요), Camera+, Dubs Mint Menus, Smarter Construction, Common Sense, Interaction Bubbles, Achtung!, Better Pawn Control, Map Preview(정착 전에 지도를 미리 보여 줘서 랜드마크 고를 때 유용).
    - 창작마당 페이지의 **'필요한 DLC'(Required DLC)**도 확인하세요. 로열티·이데올로기·어노말리가 필요한 모드는 쓸 수 없습니다.
    - 피할 것: 원조 **Replace Stuff**는 1.6 태그가 없습니다(이어받은 'Replace Stuff - Continued'는 있음). 1.6부터는 기본 게임에서도 벽·문·침대 등의 설계도를 기존 건물 위에 바로 놓아 교체할 수 있습니다. **Fluffy's Mod Manager**는 1.4에서 멈췄습니다.
    - 모드 관리는 기본 「모드」 화면(「모드 자동 정렬」 버튼 있음)이나 RimSort로 하면 됩니다.

### 튜토리얼과 「도우미」

- 메인 메뉴의 튜토리얼(「따라 해보기」 시나리오)은 「추락」 시작을 따라가며 조작법을 알려 줍니다.
- 게임 중 오른쪽 위의 「도우미」(Learning helper)는 새 개념이 나올 때마다 설명을 띄우고 검색도 됩니다. 처음 몇 시간은 켜 두세요.

## 14. 이 조합에 없는 것 [공통]

유튜브나 영어 가이드를 볼 때 아래 기능이 나오면 다른 DLC 이야기입니다. 위키에서는 페이지에 붙은 DLC 아이콘으로 구별할 수 있습니다.

| DLC | 없는 것 |
|---|---|
| 로열티 | 제국 세력, 작위·명예·특권, 사이링크와 사이캐스트(명상, 아니마 나무 포함), 왕좌실, 퍼소나 무기, **메카노이드 전초기지(mech cluster)**, 점프팩, 제국 왕복선, '왕실의 승천' 엔딩 |
| 이데올로기 | 이념(밈·계율·역할·의식), **노예**, 개종, 가우란렌 나무와 드라이어드, 유물, 고대 유적(ancient complex), 바이오스컬프터, **「영양버섯」(그래서 「어둠숲」 농사가 어려움)** |
| 어노말리 | 모노리스, 이상 개체(살덩이 괴물, 구울 등), 격리 시설, 바이오페라이트 장비, 공허 엔딩 |

'의식'이라는 말이 나와도 모두 이데올로기 것은 아닙니다. 바이오테크의 「출산」과 오디세이의 중력부양선 발사(조종사·부조종사·승무원)는 이데올로기 없이도 의식 화면으로 진행됩니다.

이 조합에서 볼 수 있는 엔딩은 기본 게임의 우주선 탈출과 오디세이의 「메카노이드 군락」입니다.
